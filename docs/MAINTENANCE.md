# Maintenance

When Governor changes:
1. identify the observed waste, stagnation, false stop, or quality regression;
2. determine whether the cause belongs to Governor or requires Scale re-plan;
3. edit the smallest authoritative layer;
4. preserve critical quality and permission boundaries;
5. run contract, benchmark-script, static, and regression checks;
6. refresh current model/surface registry facts when relevant;
7. record material changes in Git history.

Never “optimize” by silently lowering required gates.
