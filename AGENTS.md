# Agent Guidance

When working in this repository:

- Treat `SKILL.md` as canonical active runtime.
- Preserve the identity `Governor` / `governor`.
- Keep Governor inside the execution envelope; architecture changes belong to Scale/re-plan.
- Use `knowledge/README.md` for selective deeper retrieval.
- Never turn missing resource measurements into invented numbers.
- Keep current model/surface facts dated and separate from stable governance rules.
- Run static audit, contract validation, benchmark-script checks, and regression tests after structural changes.
- Do not claim model switching, quota usage, cost savings, installation, or external effects without evidence.
