# 15 — Current OpenAI Model Registry

**Snapshot: 26 September 2026. Selalu cek ulang dokumentasi resmi sebelum keputusan yang tergantung availability/limits.**

## Chat

Menurut dokumentasi OpenAI terbaru:

- GPT-5.6 Sol mendukung **Instant, Medium, High**, dan pada paket yang memenuhi syarat **Extra High**.
- Pro options mencakup GPT-5.6 Sol Pro dan GPT-6 Pro.
- GPT-6 Pro ditenagai **GPT-6 Astra** dan availability bergantung plan/workspace.
- GPT-5.6 Luna menjadi default untuk Free/Go; Think memberi Luna lebih banyak reasoning.
- Terra/Luna bukan pilihan standar di Chat berbayar biasa; availability mereka lebih relevan di Work/Codex/API.

## Work / Codex

OpenAI menyatakan Work adalah agent untuk longer multi-step work dan finished deliverables; Codex fokus software development.

Pada surface yang mendukungnya:
- **Luna:** fastest / lowest-cost member keluarga GPT-5.6; cocok high-volume low-complexity workers.
- **Terra:** balance capability, speed, dan cost untuk everyday work.
- **Sol:** complex knowledge work/research/coding/design.
- **Astra:** frontier option untuk pekerjaan profesional paling sulit; dapat mengonsumsi allowance lebih cepat daripada Sol.

Availability model dan reasoning controls berbeda menurut plan, product, rollout, dan workspace permissions. Router wajib membaca pilihan aktual yang tersedia.
